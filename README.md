Sobre este repositorio

Este repositorio contiene el sitio web de Lucero Media, publicado con GitHub Pages. Es un sitio estático (HTML, CSS y JavaScript), sin servidor ni base de datos.

index.html        portada
categoria.html    plantilla de las subcategorías de servicios
trabajo.html      plantilla de cada trabajo
data/             trabajos y clientes
assets/           logos, imágenes y reel (versiones optimizadas)

Los trabajos y clientes se cargan en data/trabajos.js.
